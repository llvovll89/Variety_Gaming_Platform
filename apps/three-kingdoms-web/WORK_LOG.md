# 작업 인계 · 2026-09-26

현재 작업 대상은 기존 Vite 앱이 아닌 `apps/three-kingdoms-web`입니다. 이 폴더 전체는 아직 Git 미추적 상태이며 커밋·배포하지 않았습니다.

## 구현되어 있는 기능

- 군주·영지 이름 입력, 장수 없이 시작, 초빙장 3장 지급.
- 36종 장수의 독립적인 1~5성 추첨, 1회·5회 모집과 결과 공개 연출. 보유 한도 300명.
- 장수 명부·도감, 이름·별호·역할 검색, 세력·등급 필터, 등급별 능력치 비교와 2D 초상.
- 부대 편성·병력 보충·영지 강화·NPC 토벌·로컬 자동 저장.
- 전투 서버 API와 DB 초기화 SQL. 화면은 로컬 체험판이며 서버 API에 연결되지 않았습니다.

- 기존 6명에 30명을 추가해 총 36명으로 확장. 촉 11명·위 12명·오 10명·군웅 3명.

- `HeroRoster.tsx`에 이름·별호·역할 검색과 세력·보유 등급 필터, 보유 표시 추가.
- 모집 확률과 수집 인원 표시가 전체 도감 인원수를 참조하도록 수정. 명부 상한은 `HERO_ROSTER_LIMIT`로 통합하고 300명으로 확장.
- 장수 상세의 3D 버튼, `HeroModel.tsx`, `heroModel.ts`, 관련 CSS 및 이 Next.js 앱의 `three`·`@types/three` 의존성 제거. 루트 Vite 게임의 의존성은 별도 용도이므로 유지.
- 기존 v2 저장 형식과 장수 키·능력치 유지. 기존 60명 저장 복원 후 새 장수 모집·편성·저장까지 회귀 테스트 추가.

- 검증 스크린샷: `demo-expanded-mobile.png`, `demo-expanded-detail.png`, `demo-expanded-summon.png` (Git 제외).
