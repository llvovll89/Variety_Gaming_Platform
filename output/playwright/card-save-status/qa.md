# 삼국 영지 저장 보호 QA — 2026-11-12

범위: 실제 저장 완료 시각, 쓰기 실패와 재시도, 실패 중 파일 백업, 저장 후 허브 복귀와 이어하기, 직전 정상 저장본 자동 보관/복구, 기존 JSON 파일 불러오기, 두 탭 동시 변경 보호, 320/390px 세로·740px 가로·1440px 데스크톱.

회귀 테스트는 레거시 저장 호환, 저장 시각/직전 원문 보존, 두 탭의 동시 쓰기, 같은 탭의 연속 쓰기, 주 저장/백업 각각의 쓰기 실패 후 재시도, 손상 원본과 정상 백업 보존, 외부 삭제, 저장소/잠금 미지원 실패를 검사한다.

실제 브라우저는 별도 Chromium 세션의 `vite preview` 배포용 빌드로 검사한다. 저장 실패는 해당 세션의 Storage.setItem에만 QuotaExceededError를 주입한다. 모달 선택을 기록하고 비동기 저장 완료를 기다리며, 화면 검사는 브라우저 시계를 고정하여 자동 저장과의 우연한 경합을 피한다. `release-smoke.js`는 Playwright CLI의 run-code --filename으로 실행하는 단일 검증 흐름이다. 사용자 브라우저의 기존 저장소는 변경하지 않는다.

전체 자동 테스트 **347/347 통과**, TypeScript/Vite 빌드 통과. 기존 Three.js 청크 크기 경고가 있다. Chromium 에뮬레이션 범위이며 실제 모바일/Safari는 검사하지 않았다. Web Locks 미지원 환경에서는 안전하지 않은 쓰기 대신 실패 안내와 파일 백업을 제공한다.

배포용 단일 검증 흐름 결과: **PASS: save/failure/retry/exit/resume/two-tabs/checkpoint/file import/four viewports**. 실제 쓰기 실패 때 이전 원문은 그대로 유지되고, 미저장 건물 강화는 파일로 내려받는다. 실패 후 허브 나가기를 취소하면 화면에 남으며, 저장소 복구와 재시도 후 허브 복귀·이어하기에서 강화 상태가 유지된다. 두 번째 탭의 농장 강화가 저장되면 첫 탭의 정방 강화 버튼이 비활성화되고 현재 진행 백업은 최신 저장본을 변경하지 않는다. 최신 기록 불러오기로 농장 2레벨이 표시되며 이전 작성 탭은 충돌 상태로 전환된다. 병영 강화 후 직전 저장본 복구는 이전 건물 배열과 일치한다. 내려받은 파일을 불러오면 원래 농장 1레벨로 복구된다. 네 화면 크기에서 가로 넘침 없음, 최종 브라우저 콘솔 오류/경고 0건. `final-*.png`, `failed-mobile.png`, `conflict-mobile.png`를 시각 검토했다.
