# 슬리더 사망 원인 — 2026-11-13

- 충돌 이벤트에 원인·상대 식별자·쌍방 여부를 추가했다. 벽 → 몸통 → 머리 순 판정과 기존 승패·처치 판정은 유지한다. 쌍방 머리 충돌은 처치자가 없어도 상대 이름이 표시된다.
- World가 사망 시점의 상대 이름과 플레이어 머리 위치를 복사하고 UI 스냅샷에 전달한다. 상대가 같은 프레임에 제거되거나 이후 위치가 변해도 결과가 보존된다.
- 결과에 원인 설명, 회피 안내, 정원 전체 지도 위 충돌 지점과 좌표를 표시한다. 자기 몸통 이벤트도 구분하지만 현재 자체 충돌 제외 반경 규칙은 변경하지 않았다.
- 새 게임·재시작·respawn에서 이전 정보가 남지 않는다.
- 자동 테스트 350/350 통과: 벽 위치 복사와 초기화, 동시 벽/몸통 우선순위, 동시에 탈락한 상대 이름, 단방향·쌍방 머리 충돌과 기존 처치자 유지.
- TypeScript/Vite 프로덕션 빌드 통과. 기존 Three.js 청크 크기와 Zod 주석 경고가 남아 있다.
- Playwright CLI의 별도 Chromium 개발 빌드에서 기존 개발용 `window.__engine` 접근점으로 합성 배치를 만들고 실제 World 충돌 → 엔진 tick → 결과 UI 경로를 검증했다. 결과 데이터 직접 주입은 하지 않았다.
- 벽·상대 몸통·쌍방/단방향 머리 충돌 메시지와 재시작 초기화, 메뉴 복귀 검증. 320×568, 390×844, 740×390, 1440×900에서 가로 넘침 없음·다이얼로그 스크롤로 복귀 버튼 접근 확인.
- 브라우저 예외 없음. 사용자 저장소·실물 모바일·Safari 검증은 포함하지 않았다.
- 별도 프로덕션 preview에서도 일반 포인터 조향과 가상 시간 진행만으로 실제 탈락 → 원인 결과 → 재시작 → 일시정지 → 메뉴 복귀를 검증했다. 배포 빌드에 개발용 엔진 접근점이 없음을 확인했다 (`production.js`, `production-log.txt`, `production-result.png`).
