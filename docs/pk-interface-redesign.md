# 삼국지 패업 PK 인터페이스 개편

## 디자인 계획과 기존 화면 점검

전면 개편 요청으로 기존 게임 규칙과 저장 형식을 유지하며 시각 구조를 새로 설계했다. 기존 화면은 종이 색상의 지도 선택 화면과 다섯 겹의 상단 정보 줄, 작은 명령 텍스트를 사용했다. 세력 선택, 도시 탐색, 장수 검색, 내정·군사·건설, PK 편집과 전투 연출은 계속 제공한다.

시작 화면은 역사 전략 게임의 전장 분위기로 읽었다. 실제 지휘 화면에는 마케팅 레이아웃 규칙을 적용하지 않고 기존 React·Three.js와 게임 전용 CSS를 사용한다. DESIGN_VARIANCE 6, MOTION_INTENSITY 3, VISUAL_DENSITY 7. 기존 Pretendard는 수치와 행동에, 시스템 Batang 계열은 군주·도시 제목에 사용한다. 바탕 #121f27, 패널 #1b2b34, 상승 표면 #263943, 구분선 #43545b, 글자 #edf0e8, 명령 강조 #e4ba70.

```
PC:     브랜드·도움말·PK 편집
        날짜·자원                     현황·저장·10일 진행
        군주 / 도시 │ 큰 전장 지도 │ 선택 정보 / 도시 명령
        군보

모바일: 날짜·자원·시간 진행
        가로 도시 목록 / 조언 펼치기
        전장 지도
        접을 수 있는 명령 패널
        군보
```

시작 화면의 전장 이미지는 기존 허브 자산 `/art/hub/three-kingdoms-large.jpg`를 재사용한다. 실제 지도는 해당 일러스트를 배경으로 붙이지 않고, 클릭 가능한 원래 3D 지형·성벽·건물을 개선한다. 텍스처는 네이티브 Canvas에서 생성하며 새 외부 이미지 의존성이 없다. 전법, 출진 비용, 도시 생산과 저장 스키마는 변경하지 않는다.

## 검증

2026-10-06 규칙·UI 테스트 66개와 TypeScript·Vite 빌드를 통과했다. 브라우저에서 군주 선택, 도시 탐색, 출진, 내정 예약과 시간 진행, 편집창과 현황창을 확인했다. 데스크톱·모바일 스크린샷은 실제 게임 화면이다.

마지막 점검에서 장수 편집창의 안내 문구에 남은 이전 테마 글자색을 수정했다. Escape로 닫을 때 저장하지 않은 변경 사항을 보호하며, 닫은 후 편집 버튼으로 키보드 초점이 돌아오는 것도 확인했다. 320×700 및 390×844 모바일 플레이 화면에는 가로 넘침이 없었다. PC·모바일 플레이와 PC 편집창의 WCAG 2 A/AA 자동 검사에서 위반은 0건이다. 지도 위 반투명 안내와 초상 배경의 일부 텍스트는 자동 명암비 계산이 불가능해 실제 캡처로 가독성을 확인했다.
