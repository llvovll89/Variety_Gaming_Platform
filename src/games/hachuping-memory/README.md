# 하츄핑 기억력

뒤집힌 카드에서 같은 동물을 찾는 짝 맞추기. 아케이드에서 가장 어린 아이를 겨냥한 게임이다.

## 빠르기가 난이도가 아니라 "나이"다

`constants.ts`의 `SPEEDS`에 붙은 설명이 이 게임의 전부다.

| 빠르기 | 배수 | 안내 문구 |
|---|---|---|
| 천천히 | 1.6 | 처음이라면 |
| 보통 | 1.0 | 익숙해졌다면 |

배수는 카드가 **보여지는 시간**에 곱해진다. 카드 수도, 짝의 개수도, 점수 계산도 바뀌지 않는다.
"쉬움/어려움"이라고 이름 붙이지 않은 이유가 여기 있다 — 아이에게 쉬움을 고르게 하는 것과
"처음이라면"을 고르게 하는 것은 다른 일이다. 기록도 빠르기별로 따로 남는다. 느리게 깬 판이
빠르게 깬 판의 기록을 밀어내지 않는다.

## 타이머를 Task로 감싼 이유

카드가 다시 뒤집히는 것, 짝이 사라지는 것, 다음 판이 시작되는 것 — 전부 `setTimeout`이다.
그대로 두면 일시정지했을 때 **뒤에서 혼자 돌아간다.** 아이가 잠깐 자리를 비운 사이 카드가
저절로 뒤집혀 있으면 게임이 고장 난 것으로 보인다.

그래서 `MemoryGameEngine`은 모든 지연 작업을 `Task` 집합에 등록하고, 일시정지에 전부 취소한 뒤
재개할 때 남은 시간만큼 다시 건다. 타이머를 직접 부르는 자리는 엔진 안에 하나도 없다.

## 동물은 다섯 종뿐

고양이·토끼·곰·여우·판다. 종류를 늘리면 판은 어려워지지만 "아, 아까 그 동물"이라는 기억의
실마리가 약해진다. 이모지로 그려서 그림 파일이 없고, 소리 내어 부를 이름이 있다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `game/engine.ts` | 카드 배치, 뒤집기 판정, 일시정지 가능한 타이머 |
| `game/constants.ts` | 빠르기, 동물 목록, 시간 상수 |
| `HachupingMemoryApp.tsx` | 화면, 조작, 기록 보고 |
| `meta.ts` | 업적과 스티커 |

빠르기는 플랫폼 설정의 `extra.speed`로도 들어온다. 허브가 `extra.difficulty`로 보내는 경우에도
같은 값으로 받아 주기 때문에, 나중에 이 게임에 난이도형 오늘의 도전이 생겨도 조용히 깨지지 않는다.

## 아직 하지 않은 것

- 판 크기가 고정이다. 카드 수를 늘리는 모드가 없다.
- 동물 울음소리가 없다. 짝을 맞췄을 때 그 동물의 소리가 나면 더 어린 아이도 즐길 수 있다.
