# 오늘의 낱말

두 글자 낱말을 여섯 번 안에 맞히는 추리 놀이. 오늘의 낱말은 날짜만으로 정해지므로 서버 없이도
모두가 같은 문제를 푼다.

## 왜 글자 단위인가

한국어는 한 글자가 뜻의 단위다. 자모만 맞히는 판정은 'ㄱㅏㅂㅏㅇ' 같은 나열이 되어 읽기 어렵고,
무엇을 알아냈는지 머릿속에 남지 않는다. 그래서 판정의 기본은 글자다.

다만 글자만으로는 단서가 너무 적다. 한글 음절은 1만 자가 넘어서, 여섯 번으로는 '초록/노랑/회색'
세 가지만 보고 좁히기가 사실상 불가능하다. 그래서 맞지 않은 글자에도 **초성·중성·종성이 각각
맞았는지**를 점 세 개로 함께 준다. 글자로 읽고 자모로 좁히는 구조다.

받침이 없다는 사실은 정답도 받침이 없을 때만 단서가 된다. 서로 다른 글자가 둘 다 받침이 없다고
해서 알려 주는 것이 없기 때문이다 (`engine.ts`의 종성 처리).

## 구성

| 파일 | 하는 일 |
|---|---|
| `engine.ts` | 음절 분해, 판정, 판 진행, 낱말 목록. DOM도 시계도 쓰지 않아 테스트가 그대로 돌린다. |
| `HangulWordsApp.tsx` | 화면과 입력, 기록 보고. 키트의 대화상자·일시정지·결과·소리를 쓴다. |
| `sound.ts` | 키트 `createGameSound` 레시피. 아케이드 소리 설정을 그대로 따른다. |
| `meta.ts` | 업적과 오늘의 도전. 타입 외에는 아무것도 import하지 않는다. |

## 오늘의 낱말

`hashSeed(\`${'${date}'}:hangul-words\`)`로 고른다. 허브의 `dailyChallenge`가 쓰는 시드와 같은 식이라,
오늘의 도전이 가리키는 낱말과 게임이 여는 낱말이 언제나 일치한다.

푼 자취는 `arcade:hangul-words:today`에 날짜와 함께 남는다. 새로 고쳐도 처음부터 다시 풀지 않고,
날이 바뀌면 저절로 버려진다.

## 오늘의 도전을 두 갈래로 나눈 이유

오늘의 낱말은 하루에 한 번뿐이라 다시 해 볼 수 없다. 그래서 "맞히기"까지만 오늘의 낱말에 걸고,
횟수를 줄이는 도전(`{n}번 안에`)은 얼마든지 다시 할 수 있는 **연습 낱말**에 건다. 한 번 어긋나면
그날은 손쓸 수 없는 약속을 내지 않기 위해서다.

## 아직 하지 않은 것

- 낱말은 286개다. 한 바퀴를 돌면 다시 나온다. 더 늘릴 수 있다.
- 추측이 실제 낱말인지는 따지지 않는다. 완성된 두 글자면 받는다. 사전을 들고 오는 대신,
  자모 단서로 좁혀 가는 쪽을 택했다.
- 결과를 글자 그림으로 공유하는 기능은 없다.
