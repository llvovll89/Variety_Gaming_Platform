# 유령 이삿짐센터

일곱 종류의 가구에 빙의해 짐을 배송하는 3D 퍼즐입니다. 신입 야간조, 이상한 가구 연구소, 한밤의 대형 이사 세 챕터에 각각 8개씩 총 24개 현장이 있습니다. 후반에는 넓은 집에서 여러 능력을 조합하고 4–8개의 짐을 운반합니다. 상자는 민트색, 옷장은 보라색 배송 발판에 도착하면 방에서 빠집니다.

- 소파: 바로 앞의 짐을 한 칸 밀기.
- 선풍기: 앞쪽 5칸 안의 짐을 바람으로 밀기.
- 냉장고: 앞쪽 4칸에 영구적인 얼음길 만들기. 옷장은 얼음 위에서 밀 수 있고 짐은 얼음 끝이나 장애물 앞까지 미끄러집니다.
- 청소기: 앞쪽 4칸 안의 짐을 자기 쪽으로 한 칸 당기기.
- 침대: 바로 앞 상자를 두 칸 튕기기. 중간 파티션을 넘을 수 있지만 착지 지점은 비어 있어야 합니다.
- 스탠드: 노란 전동문 열기/닫기. 문 위에 짐이나 가구가 있으면 닫히지 않습니다.
- 바퀴 책상: 바로 앞의 상자나 옷장을 싣고 이동하기. 다시 능력을 사용해 앞 칸에 내려야 배송됩니다.

집주인의 귀가는 실시간이 아닌 유효한 행동 수 기준입니다. 빙의, 제자리 회전, 막힌 이동에는 행동을 쓰지 않습니다. 제한이 없는 여유 모드도 있습니다. 되돌리기는 빙의 위치와 얼음길, 배송, 행동 수를 함께 복구합니다.

시작하면 유령 상태입니다. 방 안의 가구나 가구 목록을 눌러 직접 빙의하세요. 마우스·터치로 가구를 선택하고, 빈 바닥을 누르면 장애물을 우회하는 빈 길로 이동합니다. 이동은 칸마다 행동 수를 사용하고 되돌릴 수 있으며, 자동 이동은 짐을 밀지 않습니다. 짐을 누르면 선택한 가구의 사거리 안에서 접근 가능한 위치를 찾아 이동하고 짐을 바라봅니다. 그 상태에서 Space 또는 능력 버튼을 누르세요. 짐 위에 올라가서 능력을 쓰는 방식이 아닙니다.

방향키/WASD 이동, Space 능력, Q 회전, Shift+방향키 지정 회전, E 다음 가구, 1–9 가구 선택, Z 되돌리기, R 재시작, Esc 일시정지. 모바일에서는 가구 터치, 가로 스크롤 가구 목록, 방향 패드와 능력 버튼을 사용합니다. 화면의 +/− 버튼으로 방을 확대/축소할 수 있습니다. 드래그와 스크롤은 이동으로 처리하지 않습니다. WebGL 대체 화면에서도 타일과 짐을 눌러 같은 조작이 가능합니다.

진행도와 최고 별/행동 수는 `gh-ghost-movers-v1`에 저장합니다. 기존 8단계 저장 기록을 그대로 이어받고, 기존 캠페인을 완료했다면 9번째 현장이 열립니다. 3별은 힌트 없이 기준 행동 수 이내 완료, 2별은 기준+10 행동 이내, 나머지는 1별입니다. 저장이 막힌 환경에서는 현재 세션의 다음 의뢰 진행이 가능합니다.

게임 규칙은 순수 상태 전환 함수 `act`에 있습니다. Three.js로 가구·짐·유령을 실제 3D 메시로 렌더링하며, 이동 보간, 그림자, 빙의 표시와 침대 점프 애니메이션을 지원합니다. WebGL을 사용할 수 없으면 조작 가능한 2D 격자 화면을 표시합니다. 모든 24개 현장의 해법, 충돌, 얼음, 운반, 전동문, 되돌리기 및 저장 호환성은 `tests/ghost-movers.test.mjs`에서 검증합니다.
