# 텐 세컨즈 · 시간의 잔상

10초 동안의 이동을 기록하고 과거의 자신과 협동하는 3D 퍼즐 액션. 6개 방의 발판, 시간 문, 주기 레이저, 기억 결정을 연결해 탈출한다.

- WASD / 방향키 이동, R 되감기, Escape 일시 정지. 모바일은 터치 방향 버튼.
- 바닥·발판·출구를 클릭하거나 터치하면 접근 가능한 경로로 이동한다. 잔상이 열 예정인 문 앞에서는 기다렸다가 통과하며, 수동 방향 입력으로 자동 이동을 취소한다.
- 상단 게임 방법과 첫 방의 상태별 3단계 따라하기. 최초 첫 방과 설명의 따라하기는 시간 제한 없이 연습하며, 움직이지 않는 대기 시간은 첫 녹화에서 제외한다.
- 모바일은 등각 시점에 맞춘 방향 버튼, 길게 누르기·손 떼기·다중 터치 처리, 고정 되감기 버튼과 안전 영역 여백 지원. 작은 세로 화면·가로 화면·태블릿에서도 조작 버튼을 유지한다.
- 60Hz 고정 시간 기록. 잔상은 녹화한 위치와 방향을 재생하고, 일찍 되감은 기록은 마지막 위치로 10초까지 채운다.
- 최대 4개 잔상. 마지막 잔상 삭제와 방 재시작 지원. 삭제할 때도 현재 시간은 처음으로 돌아간다.
- 레이저 접촉은 현재 기록만 지우고 잔상과 결정을 유지한다. 유령은 과거의 녹화된 궤적을 그대로 재생한다.
- 문은 요구 발판이 모두 활성화되어야 통과 가능. 수집한 결정은 되감기와 레이저 접촉에도 유지된다.
- 방 해금과 최고 별점은 로컬 저장. 저장 불가 환경에서도 현재 세션 진행 가능.
- Three.js 코드로 구성한 태엽 탐험가, 반투명 유령, 이동 애니메이션, 연구실 모델. WebGL을 사용할 수 없으면 2D 등각 렌더로 대체한다.
- 외부 모델·텍스처·추가 패키지가 필요 없다. 허브 표지는 자체 SVG.

검증: `node --test tests/ten-seconds.test.mjs tests/ten-seconds-ui.test.mjs` / `npm.cmd run build`.
