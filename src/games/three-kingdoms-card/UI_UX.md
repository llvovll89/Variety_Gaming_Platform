# 삼국영지: 영지 운영과 군령 중심 UI

## 방향

삼국지W를 모티브로 한 장수 수집·육성·부대 운용 경험에 맞춰 허브의 삼국영지 화면을 개편한다. 원본 홈페이지 직접 열람은 실패했으므로 원본 화면을 재현했다고 주장하지 않는다. 기존 초상과 배경 자산을 활용한다.

색상: 블랙 `#080808`, 배경 `#101010`, 패널 `#151515`, 선택 표면 `#232323`, 경계 `#303033`, 본문 `#ededed`. 실버를 조작 강조색으로 사용하고 장수 등급·병종·전투 결과에 의미 있는 색을 남긴다. 베이지 군사 보고와 목재 표면은 제거했다. 군주·장수·화면 제목과 본문·명령·수치는 모두 Pretendard Variable로 통일한다. 제목은 700~750, 본문은 400~500 굵기를 사용한다. 가변 폰트 서브셋을 로컬 패키지에서 로드하며 별도 Google Fonts 명조 요청은 제거했다. 숫자는 고정 너비 숫자로 정렬한다.

```
군주 / 군령 메뉴 | 본성 / 금 / 식량 / 예비군 / 초빙장
                 | 영지 주변 지도       | 군사 보고
                 | 본성 · 토벌 거점     | 주장 · 다음 명령
                 | 내정 현황 / 일일 과제 / 건물 강화
```

본문과 조작은 왼쪽 정렬, 자원은 묶음별 정렬, 장수 능력치는 열별 비교를 우선한다. 모바일은 하단 군령 메뉴와 한 열 지휘소로 전환한다.

## 계획 검토와 수정

기존의 남색 화면·붉은 인장·모집 홍보 문구만으로는 일반적인 수집 게임과 구별하기 어렵다. 모집관을 첫 화면으로 쓰던 구성을 영지 지휘소로 바꾸고, 본성·실제 토벌 대상·병력·완료 상태가 연결되는 작전 지도를 중심 요소로 삼았다. 사용자 스크린샷을 검토한 뒤 갈색·문서색 표면도 블랙과 실버로 수정했다. 카드의 과한 부상 효과와 고등급 광택도 줄였다.

## 구현

- 기본 진입: 영지 지휘소. 실제 상태에 따라 모집 → 편성 → 병력 보충 → 출정을 안내한다.
- 지도: 본성은 영지 관리, 토벌 거점은 출정 화면으로 연결한다. 토벌 완료와 주둔 병력을 표시한다.
- 명부: 장수 카드 / 능력치 목록 전환. 기존 검색·세력·등급·정렬을 양쪽에 동일하게 적용한다.
- 편성: 가용 식량·예비군·병력 수용량을 계산한 최대 보충량 선택과 입력 검증.
- 출정: 교전 규칙과 아군·적군의 편성을 확인한 뒤 명령을 실행한다. 명령 확인과 전투 결과로 키보드 포커스를 이동한다.
- 전투: 계산 시 공격별 실제 잔여 병력을 기록한다. 재생·정지·이전·다음·탐색·결과 보기는 이 기록을 조회하며 전투를 다시 계산하지 않는다.
- 저장: 기존 version 2 형식 유지. replay 없는 이전 전투는 전문을 통해 열람한다.
- 군정: 연구·파견·누적 공적을 한 화면에서 관리한다. 영지 요약과 메뉴 배지로 완료·수령 가능한 항목을 안내한다.

전투의 병종 상성·선공·계략·반격 계산은 유지하고 병법 연구의 방어 효과를 추가했다. 서버용 별도 Next.js 앱은 이번 변경 대상에 포함하지 않았다.

| 매초 전체 명부를 localStorage에 직렬화함 | 표시 1초, 자동 저장 15초. 사용자 행동과 숨김·페이지 종료 시 즉시 저장 |

연구 효과는 최대 자원 생산 +50%, 병력 수용량 +30%, 피해 감소 +15%다. 비용은 다음 레벨의 제곱, 시간은 다음 레벨의 1.5제곱에 비례한다. 30개 연구를 차례로 진행하는 데 대기 시간만 약 9일이 필요하다. 이는 장기 목표의 하한이며, 실제 플레이 잔존율을 측정한 수치는 아니다. 파견 보상은 출발 시 확정해 저장하고 귀환 수령 시 한 번만 반영한다.

## UI 구조 점검에서 수정한 항목

- 초반 NPC의 알 수 없는 templateKey가 관우 초상으로 대체되던 오류: 적군 표식으로 표시.
- 전군 출정 뒤 보고서 선택이 남아 있던 오류: 가장 최근 전투를 선택.
- 출정 메뉴로 돌아올 때 과거 전투 보고로 자동 스크롤하던 문제: 보고서가 실제로 변경될 때만 포커스 이동.
- 큰 자원 수치: 헤더에서 만·억 단위로 표시, title과 접근성 이름에 정확한 수치 제공.
- 긴 영지·장수 이름: 제목·지도·보고서·카드의 최소 너비와 줄바꿈 보완.
- 모바일 3열 편성: 작은 초상과 장수 선택을 묶은 1열 배치로 전환.
- 모바일 검색 도구: 검색은 한 행, 나머지 조건은 두 열로 배치.
- 장수 상세 표: 고정 열 너비와 줄바꿈으로 긴 특수능력명 수용.
- 지도 본성과 일일 과제 버튼: 같은 탭을 재선택하던 동작을 실제 내정·과제 영역으로 스크롤하도록 수정.
- 작은 높이의 데스크톱: 왼쪽 메뉴 내부 스크롤 제공.
- 모바일 6개 메뉴: 하단을 같은 너비 6칸으로 구성.
- 부대 선택의 tab 역할 오용: 실제 동작에 맞는 group과 aria-pressed로 수정.

모바일 기준 규칙은 640px 이하에서 적용한다. 320·375·640px에서는 한 열 군정·편성, 900px 이하에서는 압축 사이드 메뉴와 한 열 연구를 사용한다. 장수 능력치 비교 표만 의도적으로 내부 가로 스크롤을 허용한다.

## 검증 한계

브라우저 연결이 없어 스크린샷 기반 시각 검수와 실제 모바일 터치 검수는 수행하지 못했다. 배포 전 데스크톱·모바일에서 지도 표식, 명부 가로 스크롤, 출정 확인 포커스, 재생 조작을 확인해야 한다.

## 검증 결과

전체 테스트 290개 통과. 그중 삼국영지 규칙·저장 테스트 37개, 화면 상태 렌더링 테스트 4개를 포함한다. 연구 30레벨을 여러 날에 걸쳐 완료하는 시뮬레이션, 기존 저장 이관, 파견 보호, 보상 중복 방지, 대규모 자원 표기를 검증했다. TypeScript 및 Vite 프로덕션 빌드 통과. 실제 브라우저의 픽셀 배치나 모바일 터치 동작은 자동 테스트로 대체했다고 주장하지 않는다.

### 추가 콘텐츠

- 장수 72 → 88명. 비의·동윤·장억·요화·조홍·이전·악진·진군·한당·장흠·반장·보연·고순·진궁·유표·채염. 각 전용 초상과 특수능력, 1~5성 모집 지원.
- 병종 3 → 6종. 창병·기병·궁병에 도순병·노병·궁기병 추가. 각 병종은 유리 2종, 불리 2종, 자신 외 중립 1종을 갖는다. 기존 3종의 상성은 유지한다.
- 도순병: 피해 감소 8%, 가하는 피해 감소 4%. 노병: 계략 배율 +0.15, 선제 통솔 −10. 궁기병: 첫 턴 피해 +10%, 받는 피해 +4%.
- 진형 4 → 8종. 안행진·학익진·방진·팔괘진 추가. 각 진형의 배치 도식·기본 효과·추가 숙련 조건을 표시한다. 도식은 부대 전체 진법의 개념도이며 개별 병사의 위치를 시뮬레이션하지 않는다.
- 진형 숙련은 주장 지력·역할·세력 다양성·3명 편성 같은 실제 조건을 검사한다. 조건을 충족할 때만 전투 효과를 더한다.
- 장수 인연 8종. 도원의 맹세·와룡과 봉추·오자양장의 군율·강동의 원로·함진의 계책·북벌의 뜻·서량의 기마·강동의 외교. 같은 장수 복제 카드로 인원 수를 부풀릴 수 없다.
- 모의전: 현재 편성과 잔여 적 병력으로 실제 전투 엔진을 실행한다. 상태를 수정하지 않고 보상은 0이며 저장 전투 기록에도 남기지 않는다. 결과는 무작위 1회 표본으로 승률 보장이 아니다.
- 장수 상세에 적성 병종·인연·보유 여부를 표시해 다음 수집 목표를 찾도록 했다.
- 신규 88명 도감 보상과 '천하귀심' 공적을 추가. 공적은 총 13종이며 기존 수령 기록은 유지한다.

### 검증

전체 299개 테스트 통과. 삼국영지 규칙·저장 43개 및 UI 구조·상태 7개를 포함한다. 병종 간 상성의 대칭성과 각 2개 유불리, 48개 병종·진형 조합, 인연의 중복 방지, 조건부 숙련, 무손실 모의전, 신규 장수의 등급별 저장과 초상 자산을 검사했다. 스크린샷의 두 결함은 모달의 정렬·스크롤 CSS 및 모든 등급의 2행 스킬 구조에 회귀 검사를 추가했다. 다른 삼국지 게임의 기존 전용 초상은 공유 카탈로그가 늘어나도 바뀌지 않도록 우선순위를 보존했다.

실제 브라우저 재촬영과 모바일 기기의 터치 검수는 여전히 미완료다. 생성된 초상 아틀라스는 직접 열어 확인했다. 신규 이미지와 제작 프롬프트는 [ART_ASSETS.md](ART_ASSETS.md)에 기록했다.

## 연무관 확장

출정 화면 내부를 토벌 / 연무탑 / 요일 전장 / 교환소로 나눴다. 기존 하단 메뉴의 여섯 칸은 유지한다. 지휘소에 연무관 바로가기와 최고 돌파 층·전공 잔액을 표시한다.

- **연무탑 30층:** 순서대로 돌파한다. 통과한 층은 무제한 복습할 수 있지만 최초 승리 이후 추가 보상은 없다. 층마다 적 병종·진형·장수가 바뀌고 11층·21층부터 부장이 늘어난다.
- **요일 전장:** 요일에 따라 도순병·기병·노병·궁병·궁기병·창병 또는 전체 병종에 효과를 부여한다. 효과는 양군에 동일하게 적용한다. 초급·중급·상급을 선택하며 승패에 관계없이 하루 3회 도전한다. 전공 보상은 각각 10·20·30이다.
- **훈련 병력:** 양군 모두 1,000명으로 전투한다. 실제 잔여 병력·예비군·식량을 차감하지 않는다. 장수의 현재 능력치, 특수능력, 연구, 병종, 진형, 인연은 그대로 적용한다. 빈 병력으로도 주장이 배치되어 있으면 참여 가능하다.
- **고정 조건:** 연무탑은 층, 요일 전장은 날짜·난이도를 기반으로 고정 난수열을 사용한다. 동일 편성·조건의 결과를 재현할 수 있어 반복 추첨보다 편성 변경을 시험하는 데 집중한다. 로컬 AI 도전전이며 실제 유저 대전이나 서버 순위가 아니다.
- **전공 교환소:** 20전공으로 초빙장 2장(하루 2회), 15전공으로 경험치 500 병법서(하루 3회), 120전공으로 요화·이전·한당·고순 중 선택한 3성 장수(하루 1회)를 교환한다. 경험치는 기존 학습 특수능력 보너스를 적용한다. 금·전공 상한을 초과하면 보고서는 실제 지급량만 표시한다.
- **편성 프리셋 3개:** 주장·부장 카드 ID, 병종, 진형, 이름을 저장한다. 저장 시 병력은 복제하지 않는다. 적용 시 수용량을 넘은 실제 병력은 예비군으로 반환한다. 미보유 장수, 다른 부대나 파견에서 사용 중인 장수가 있으면 원자적으로 거부한다. 장수를 방출해도 과거 프리셋 때문에 저장 파일 전체가 무효화되지 않으며 해당 프리셋만 적용할 수 없다.
- **기록:** 최신 도전전 보고서와 재생 자료를 별도로 보존한다. 실제 토벌의 병력 손실 기록과 혼동하지 않게 분리하고 지급된 전공·금·경험치를 표시한다. 날짜가 바뀌어도 전공·층 돌파·프리셋은 유지되고 도전·교환 횟수만 초기화된다.

이전 v2 저장에서 `warRoom`과 `presets`가 없으면 초기값으로 이관한다. 기존 연구·파견·보유 장수에는 변경을 가하지 않는다.

검증: 전체 테스트 309개 통과, TypeScript 및 프로덕션 빌드 통과. 규칙·저장 테스트 51개, UI 구조·상태 테스트 9개를 포함한다. 층 건너뛰기·범위 오류, 보상 중복, 무손실 훈련, 동일 조건 재현, 승패 모두의 횟수 차감, 일일 초기화, 교환 재고·잔액, 프리셋의 병력 반환·파견 보호·이관을 검사했다. 5성·100레벨의 실제 획득 가능 포인트(장수별 297)를 배분한 파티와 연구를 사용해 30개 층 각각에 승리 가능한 병종·진형 조합이 있음을 시뮬레이션했다. 플레이 유지율이나 전체 유저의 난이도 분포를 검증한 것은 아니며 실화면 재촬영은 여전히 미완료다.
## 대장간과 장수 보호 확장

군정 안에 대장간을 추가했다. 선봉·책략·수호 3계열에 무기·방어구·보물 각 1종씩 총 9종이며, 장수마다 슬롯별 하나를 착용한다. 2개·3개 세트 효과와 장비 능력치는 실제 전투에 반영한다. 전투 효과는 주장 100%, 부장 30%이며 장비 능력치는 기본 배분 상한과 별도다. 장수 상세와 명부 능력치에도 장비 보너스를 반영한다.

- 제작: 금 300, 철재 15. 시작 철재 30. 보관 한도 300개.
- 강화: 최대 +10, 확정 성공. 현재 강화 단계 n에서 다음 단계 비용은 금 150×n², 철재 5×n이다.
- 분해: 미장착 장비만 가능하며 제작·강화에 투자한 철재의 절반(내림)을 반환한다. 확인 후 소모하며 금은 반환하지 않는다.
- 철재 공급: 토벌 승리로 적 거점을 격파하면 min(10, 2+전투 단계), 연무탑 최초 승리는 3+floor(층/5), 요일 전장 승리는 난이도×4, 소탕은 3이다. 연무탑 재도전과 모의전은 지급하지 않는다.
- 슬롯 교체와 장비 이전은 기존 장비를 보관함으로 돌려보낸다. 통솔 감소와 능력치 초기화 시 모든 부대의 초과 병력을 예비군으로 반환한다. 장수 방출·승급 재료 소모 시에도 해당 장비는 보존한다.
- 장수 상세에서 즐겨찾기·잠금을 설정한다. 잠금은 직접 방출·일괄 방출·승급 재료 사용을 막고, 즐겨찾기는 일괄 방출·승급 재료에서 제외한다. 명부는 즐겨찾기 필터를 제공한다.

이전 저장에 `forge`, `locked`, `favorite`가 없어도 기본값으로 불러온다. 장비 ID 중복, 없는 장수에게 귀속된 장비, 한 장수의 동일 슬롯 중복은 저장 검증에서 거부한다. 장비와 병력 수는 편성 프리셋에 저장하지 않고 현재 장착 상태를 적용한다.

검증: 전체 자동 테스트 317개 통과. 제작·강화 비용, 장비 이전, 세트 전투 반영, 병력 반환, 분해 회수율, 장수 보호, 승급 시 장비 보존, 철재 재지급 방지, 기존 저장 이관과 UI 렌더링을 검사했다. 실제 브라우저 및 모바일 실화면 검수는 미완료다.
