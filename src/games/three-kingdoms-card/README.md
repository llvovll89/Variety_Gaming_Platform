# 삼국 영지

장수를 모으고 부대를 짜서 거점을 토벌하는 전략 게임. 아케이드에서 가장 규칙이 많다.

## 전투에 조작이 없다. 편성이 전부다

전투가 시작되면 플레이어가 할 일이 없다. `simulateBattle`이 끝까지 돌리고 결과를 재생해 보여
줄 뿐이다. 그래서 이 게임의 재미는 **전투 전에** 있다 — 어떤 장수를 주장으로, 어떤 병종으로,
어떤 진형으로.

그 선택이 의미를 가지려면 효과들이 서로 다른 축에 놓여야 한다. 지금 다섯 축이 있다.

| 축 | 고르는 것 | 보기 |
|---|---|---|
| 병종 상성 | 창 > 기 > 궁 > 창 | 유리 ×1.25, 불리 ×0.8 |
| 적성 | 주장 역할과 병종 일치 | 피해 +10% |
| 진형 | 8종, 전부 장단이 있다 | 어린진 피해 +15% / 받는 피해 +10% |
| 진형 공명 | 진형이 요구하는 편성 | 추행진 + 기장 1명 → 선제 +15 |
| 세력 시너지·인연 | 같은 세력 2~3명, 특정 조합 | 도원의 맹세(유·관·장) |

진형에 **순수한 상위 호환이 없는 것**이 설계의 핵심이다. 모든 진형이 무언가를 내주고 무언가를
얻는다(`FORMATIONS`의 음수 값이 약점이다). 하나라도 공짜로 강하면 나머지 일곱은 존재하지 않는
것과 같다. 기본진조차 "보정 없음"이라는 선택지로 남아 있다.

부장은 능력치도 특수능력도 **30%만** 기여한다. 100%였다면 세 명을 균등하게 채우는 것이 늘
정답이 되어, 주장을 누구로 둘지가 질문이 아니게 된다.

## 전투 계산기는 시계도 저장소도 모른다

`simulateBattle(attacker, defender, random)` — 무작위는 인자로 받는다. 소스 주석이 못 박아 둔다:
"RNG는 명시적이다. 시계도, 데이터베이스도, 입력 변형도, 숨은 무작위도 없다."

덕분에 같은 시드로 같은 결과가 나오고, 테스트가 전투 수천 판을 즉시 돌릴 수 있다. 실제로
오늘의 도전을 넣을지 판단할 때 이 함수를 직접 돌려 턴 분포를 쟀다.

입력 검증도 여기 있다 — 부장 3명 이상, 음수 병력, 100만 초과, 능력치 10000 초과는 던진다.
저장 파일은 플레이어가 고칠 수 있는 곳에 있으므로, 계산기가 자기 입력을 믿지 않는다.

## 저장은 잠금 안에서 비교하고 쓴다

`localSave.ts`의 `LocalSave`는 단순히 `setItem`하지 않는다.

1. 같은 탭의 쓰기는 `queue`로 직렬화한다.
2. 브라우저 전역 잠금(`exclusive`) 안에서, 저장소의 현재 값이 **내가 마지막으로 쓴 값과 같은지**
   확인한다. 다르면 다른 탭이 썼다는 뜻이므로 `conflict`를 돌려주고 덮어쓰지 않는다.
3. 덮어쓰기 전에 **검증을 통과한** 이전 값만 백업에 남긴다. 깨진 저장을 백업에 넣으면 복구
   화면이 깨진 것을 제안하게 된다.

두 탭에서 같은 영지를 열어 두는 일은 실제로 일어난다. 그때 조용히 한쪽의 두 시간을 날리는 대신
충돌을 알린다.

## 오늘의 도전을 일부러 넣지 않았다

`meta.ts`의 주석이 이유를 적어 두었고, 추측이 아니라 전투 계산기를 돌려 확인한 것이다.

- **연무탑**은 층마다 시드가 고정이다. 같은 부대면 결과가 늘 같고, 승리는 2~3턴에 끝난다.
  "N턴 안에 승리"가 도전이 아니라 통보가 된다.
- **토벌**은 전투가 끝나도 상대 병력이 남아 다음 전투로 이어진다. 거의 쓰러진 상대를 골라
  때리면 턴 수를 얼마든지 낮출 수 있다.

쓸 만한 척도(피해 비율, 무손실 승리 같은 것)를 새로 보고하기 전까지는 지킬 수 없거나 속이기
쉬운 약속을 내지 않는다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `lib/battleEngine.ts` | 전투 계산. 순수 함수, 무작위는 인자 |
| `lib/tactics.ts` | 병종 상성, 적성, 진형 8종과 공명 |
| `lib/synergy.ts` | 세력 시너지와 장수 인연 |
| `lib/heroCatalog.ts` + `expansion*.ts` | 장수 데이터 |
| `lib/demoGame.ts` | 전체 상태와 zod 스키마 |
| `lib/localSave.ts` | 충돌 감지 저장 |
| `lib/campaign.ts` · `progression.ts` · `challenges.ts` | 거점, 성장, 게임 자체의 일일 과제 |
| `components/tabs/` | 토벌·편성·모병·단조·영지·도전 탭 |
| `resume.ts` | 허브의 "이어하기" 라벨 |

## 아직 하지 않은 것

- 오늘의 도전이 없다(위 참조). 전투당 피해 비율이나 무손실 여부를 보고하면 열린다.
- `components/GameDemo.tsx`가 거의 모든 상태를 쥐고 있다. 탭이 늘어날수록 부담이 커진다.
- 전투 중 개입이 전혀 없다. 한 번쯤 계략을 고르는 선택지가 있으면 재생이 관람이 아니게 된다.
