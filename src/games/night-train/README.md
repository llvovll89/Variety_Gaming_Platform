# 별빛 야간열차

새벽역까지 달리는 밤 열차에서 견습 차장이 카드로 그림자 승객을 물리치는 로그라이크 덱빌딩 게임입니다. 한 판마다 노선도, 적 조합, 보상 카드가 새로 정해지고, 체력이 0이 되면 처음부터 다시 출발합니다.

## 한 판의 흐름

1. 개찰 펀치 5장, 외투 여미기 4장, 랜턴 비추기 1장으로 된 시작 덱과 유물 "작은 랜턴"을 들고 출발합니다.
2. 노선도는 12개 역과 종착역(보스)으로 이루어집니다. 7번째 역은 모두 화물칸(유물), 12번째 역은 모두 침대칸(휴식)으로 고정되어 있습니다. 초반 네 역에는 강적 칸과 침대칸이 나오지 않습니다.
3. 전투는 매 턴 증기(에너지) 3, 카드 5장으로 진행합니다. 적의 다음 행동은 머리 위 꼬리표로 미리 보여 줍니다.
4. 전투에서 이기면 골드를 받고 카드 3장 중 1장을 고릅니다(넘길 수도 있음). 강적을 이기면 유물도 받습니다.
5. 종착역의 "새벽을 삼킨 검은 기관차"는 체력이 절반 아래로 떨어지면 폭주하며, 그 순간 다음 행동이 바로 바뀝니다.

## 콘텐츠

- 카드 31종: 시작 카드 3종, 일반 12종, 고급 10종, 희귀 6종. 모든 카드는 침대칸이나 이벤트에서 강화할 수 있습니다.
- 적 9종: 일반 5종, 강적 3종(쌍둥이 램프는 두 마리가 함께 나옴), 보스 1종.
- 유물 12종(시작 유물 포함), 이벤트 5종, 상태 효과 8종(힘, 약화, 취약, 화상, 가시, 철갑, 시간표, 불꽃 엔진).
- 난이도 2단계: 일반석·보통(체력 70)과 침대석·여유(체력 85, 적 체력 -25%).

## 간식

가방 세 칸에 담아 두는 소모품 7종입니다. 증기(에너지) 없이 전투 중 언제든 먹을 수 있고, 코코아는 노선도에서도 마실 수 있습니다. 일반 전투 보상의 25%, 강적 보상의 50%에 간식이 섞여 나오고, 매점에서도 세 가지를 팝니다. 처음에는 별사탕 한 줌을 하나 들고 출발합니다.

## 아트 디렉션

"1930년대 야간 급행 인쇄물"이 콘셉트입니다. 타이틀과 전투는 남색 밤 장면에 놋쇠와 램프 빛을 쓰고, 노선도·매점·보상·대화상자처럼 읽거나 고르는 화면은 종이 인쇄물로 처리했습니다. 서체는 Pretendard Variable 한 가지로 통일하고, 굵기(400~900)와 자간으로 위계를 만듭니다. 모서리는 작게, 그림자는 인쇄물처럼 짧고 단단하게, 발광 효과는 쓰지 않습니다.

- 카드: 천공이 뚫린 승차권. 비용은 펀치 구멍, 종류는 상단 색 띠(공격 적색, 기술 녹색, 능력 보라), 희귀도는 점 세 개로 표시합니다. 힘·약화·취약으로 바뀐 숫자는 초록(증가)·적색(감소)으로 보입니다.
- 적의 다음 행동: 머리 위에 매달린 수하물 꼬리표.
- 전투 배경: 창밖 풍경이 흘러가는 객차 내부(보스전은 새벽빛).
- 아이콘: `ui/glyphs.tsx`의 전용 아이콘 약 60개. 24px 격자, 1.75 선, 한 가지 옅은 채움으로 통일했습니다.
- 캐릭터: `ui/cast.tsx`의 동화책풍 SVG 일러스트 10종(차장과 적 9종). 잉크 외곽선 한 색(#1b1626), 왼쪽 위 램프의 따뜻한 빛과 오른쪽의 차가운 그림자, 빛을 받는 쪽의 림 라이트, 눈 하이라이트를 모든 캐릭터에 같은 규칙으로 적용했습니다.

## 전투 연출

- 카드는 끌어서 놓거나 두 번 눌러서 씁니다. 대상이 필요한 카드를 끌면 조준선이 나타납니다.
- 턴을 마치면 엔진이 적의 행동을 한 박자씩 기록(`combat.frames`)하고, 화면은 이를 0.8초 간격으로 다시 재생합니다. 재생은 저장하지 않습니다.
- 턴 리본, 카드가 대상에게 날아가는 연출, 8 이상 피해 때 화면 흔들림, 쓰러진 적이 사라지는 연출이 있습니다.
- 전투가 끝나면 마지막 장면과 승리·패배 리본을 잠깐 보여 준 뒤 보상 화면이나 결과로 넘어갑니다.

## 구조

```text
engine/          DOM을 모르는 순수 규칙 (node --test로 검증)
  types.ts       저장 가능한 상태 타입과 명령
  rng.ts         시드 난수(mulberry32). 상태가 런에 저장되어 이어하기도 같은 운을 이어 갑니다.
  cards.ts       카드 정의와 카드 설명 문구 생성
  enemies.ts     적 정의, 행동 패턴, 조우 목록
  combat.ts      피해 계산, 카드 사용, 적 턴
  map.ts         교차하지 않는 노선도 생성
  run.ts         act(state, command): 상태를 바꾸지 않고 새 상태를 돌려주는 단일 진입점
  save.ts        zod 저장 검증과 기록
ui/              React 화면 (전투, 노선도, 보상·상점·휴식·이벤트·화물칸)
```

턴제 게임이라 rAF 루프 없이 React 상태로 그립니다. 모든 규칙은 `act`를 거치고, 허용되지 않는 명령은 같은 객체를 그대로 돌려줍니다. 화면은 "이 카드를 쓸 수 있는가"를 엔진의 `checkPlay`에 물어보기 때문에 규칙이 두 군데로 갈라지지 않습니다.

카드 설명의 숫자는 지금 상태를 반영합니다. 힘·약화가 걸렸거나 대상이 취약이면 손패에 실제로 들어갈 피해가 표시됩니다.

## 저장

- 진행 중인 여행: `arcade:night-train:run`. 명령마다 자동 저장하고, 전투 도중에도 이어 할 수 있습니다. 불러올 때 카드·유물·적 id, 체력 범위, 노선 경로를 검증하고, 깨진 저장은 무시합니다.
- 기록: `arcade:night-train:records` (여행 횟수, 새벽 도착 횟수, 최고 도달 역, 최고 점수).
- 점수 = 통과한 역 × 10 + 강적 × 25 + 골드 / 10, 보스를 이기면 +200.

## 조작

카드를 한 번 누르면 고르고, 한 번 더 누르면 씁니다. 적이 여럿일 때 대상이 필요한 카드는 고른 뒤 적을 누릅니다. 키보드는 1~9·0 카드 선택, Enter 사용, ←/→ 대상 변경, E 턴 종료, D 덱 보기, Esc 메뉴입니다. 내 사진 캐릭터를 쓰면 차장 얼굴이 그 사진으로 바뀝니다.

## 밸런스

카드를 단순한 규칙(위협이 있으면 방어, 아니면 효율 좋은 카드부터, 위험할 때 간식 사용)으로 고르는 자동 플레이로 시드 400개씩 돌린 결과, 보통 모드 승률은 약 39%, 여유 모드는 약 82%였습니다. 간식을 넣으면서 승률이 65%까지 올라가, 간식 드롭률을 낮추고(일반 25%, 강적 50%) 보스를 강화(체력 170, 돌진 22, 경적 6×3)해 원래 수준으로 되돌렸습니다. 패배의 대부분은 보스전에서 나오고, 그다음은 강적 칸입니다.

## 소리

- 효과음 29종과 기차 주행음을 Web Audio API로 브라우저에서 바로 합성합니다(`ui/sound.ts`). 녹음 파일이 없어 라이선스 걱정이 없고 다운로드 용량도 늘지 않습니다.
- 어떤 일에 어떤 소리를 낼지는 엔진의 순수 함수가 정합니다(`engine/cues.ts`). 화면에 뜬 피해·방어·상태 효과(`cuesForFx`)와 이동·보상·매점·휴식·이벤트 같은 진행 변화(`cuesForRunChange`)가 대상이고, 테스트로 검증합니다.
- 전투: 카드 집기, 카드 날리기, 타격(피해가 클수록 무겁게), 피격, 방어, 완전 방어, 회복, 강화·약화, 턴 종료 레버, 내 차례 기적, 상대 차례 경적, 승리·패배 음악, 보스 폭주 포효, 증기 부족 경고음.
- 기차 주행음: 노선도와 전투 화면에서만 레일 이음매의 "덜컹-덜컹"과 낮은 엔진음을 냅니다. 기본값은 꺼짐입니다.
- 정책: 화면을 처음 누르기 전에는 오디오를 만들지 않습니다(브라우저 자동재생 정책). 탭이 가려지면 멈춥니다. 효과음과 주행음은 각각 상단 스피커 단추와 메뉴에서 끌 수 있고, 설정은 `arcade:night-train:sound`에 저장됩니다.

## 저작권과 웹 정책

- **그림:** 캐릭터, 아이콘, 배경, 허브 커버(`public/art/hub/night-train*.jpg`)는 모두 이 게임을 위해 코드(SVG)로 새로 그렸습니다. 외부 이미지, 생성 이미지, 다른 게임의 에셋은 쓰지 않았고, 커버는 게임 안 컴포넌트를 그대로 렌더링한 것입니다.
- **이름과 설정:** 카드·적·유물·이벤트 이름은 모두 새로 지었고, 다른 게임이나 작품의 고유 명칭·캐릭터를 쓰지 않습니다. 밤 열차, 로그라이크 덱빌딩 같은 장르와 일반 소재만 공유합니다.
- **서체:** Pretendard Variable(© Kil Hyung-jin, SIL OFL 1.1). 라이선스 전문을 `public/fonts/OFL-pretendard.txt`로 함께 배포하고, 게임 도움말에 출처와 라이선스 링크를 표시합니다.
- **소리:** 모든 효과음은 코드로 합성해 외부 음원을 쓰지 않습니다.
- **라이브러리:** React, zod(MIT).
- **개인정보:** 진행과 기록은 브라우저 localStorage(`arcade:night-train:*`)에만 저장하고 외부로 보내지 않습니다. 네트워크 요청, 쿠키, 추적 코드가 없습니다. 내 사진 캐릭터는 탭이 열려 있는 동안의 임시 URL로만 쓰이고 저장되지 않습니다.
- **접근성:** axe-core 4.10(WCAG 2.0/2.1/2.2 A·AA, best-practice)으로 타이틀·도움말·노선도·전투·보상·매점·이벤트·휴식 화면을 데스크톱과 모바일에서 검사해 위반 0건입니다. 자동 판정이 어려운 명도 대비는 직접 계산해 본문 글씨를 4.5:1 이상으로 맞췄습니다. 키보드만으로 플레이할 수 있고, 동작 줄이기(prefers-reduced-motion) 설정을 따릅니다.
