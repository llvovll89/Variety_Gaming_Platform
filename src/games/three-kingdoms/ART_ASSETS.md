## Prompt set

Each built-in imagegen call used this common prompt followed by the corresponding subjects below:

Use case: historical-scene. Asset type: production portrait sprite atlas for a Three Kingdoms strategy game. Create ONE image with EXACTLY FOUR COLUMNS and FOUR ROWS, 16 equal square tiles, aligned edge-to-edge, no gutters or borders, overall square composition, ideally 2048x2048. All 16 tiles must contain a single different East Asian adult person, realistic richly detailed painterly strategy-card illustration. Centered head-and-chest bust with fully visible face and headgear, leave 8% headroom inside each tile. Ancient Han-inspired fine silk, ornate bronze and steel lamellar armor, cinematic warm bronze rim lighting, dark smoky navy backgrounds. No 3D low-poly, no silhouettes, no text, labels, numbers, logos or watermarks. The specified tile order is strict left-to-right, top-to-bottom. Portraits are fictional original interpretations, never copy commercial game artwork.
