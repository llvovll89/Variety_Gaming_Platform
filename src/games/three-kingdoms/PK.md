# 삼국지 패업 PK

## 삼국지 11과의 차이 분석

공식 소개의 핵심은 하나의 지도에서 도시 개발과 야전이 이어지는 구조, 병과별 전법으로 적의 위치를 바꾸는 전술, 장수 최대 3명으로 구성하는 부대다. 기존 패업은 육각 지도와 내정·출진 규칙이 있었지만 평면 Canvas 그림, 하단의 긴 명령창, 월 단위 진행과 단순 피해 중심 전투 때문에 원작과 조작 감각이 달랐다.

- [공식 한 장 지도 소개](https://www.gamecity.ne.jp/sangokushi/11wpk/game/01.htm)
- [공식 부대 편성·전법 소개](https://www.gamecity.ne.jp/sangokushi/11wpk/game/02.htm)
- [공식 PK 시설 합병 소개](https://www.gamecity.ne.jp/sangokushi/11wpk/pwp/01.htm)

## 이번 구현

- Three.js 원근 카메라와 실제 3D 지형·성곽·시설·장수·병사·기마 모델. 좌우 회전, 시점 변경, 확대·축소, 선택 격자. 이름표와 3D 오브젝트도 클릭할 수 있다. WebGL 불가 시 기존 2D 호환 표시를 사용한다.
- 데스크톱 우측 명령창, 전도에서 도시 이동, 상단 날짜·자원·명령. 모바일에서는 지도 아래에 높이를 제한한 명령창을 배치한다.
- 한 턴 10일(상순·중순·하순). 내정과 이동·전투는 매 순, 수입·주둔군 유지비는 월말 정산. 기존 9월 수확 유지.
- 공격 확인 창은 복제한 게임 상태에 같은 전투 규칙을 실행해 피해를 표시하며 실제 상태와 난수는 건드리지 않는다. 취소 가능.
- 창병 돌출·기병 돌격은 생존한 적을 뒤로 한 칸 밀어낸다. 이동 불가·점유·도시로 막히면 기본 피해의 20% 충돌 피해. 아군 및 점유 인덱스를 덮어쓰지 않는다. 잘못된 대상, 병과에 맞지 않는 전법, 행동 완료 부대의 공격은 거부한다.
- 장수 39 → 120명. 제갈량·방통·사마의·마초·육손·강유·등애·종회 등 포함. 시대가 다른 영웅을 194년 지도에 함께 배치한 가상 시나리오다.
- 삼국지 7~11을 조사해 종이·먹색·청동 테두리와 주홍 인장을 적용했다. 메인에서 세력과 실제 시작 자원을 확인한 뒤 시작하며, 도시 명령은 내정·군사·건설 탭으로 나눈다. [UI/UX 조사와 적용](UI_UX.md).
- 공격 확인에서 전투 보기 또는 즉시 결과 선택. 개별 장수 모델이 등장하는 3D 전투 팝업에 실제 전투 전후 병력과 전법 결과를 표시한다. 스킵은 연출만 생략하며 전투를 다시 계산하지 않는다. 아군이 관여하는 적 턴 전투도 일시정지하여 보여 주며 해당 턴 전체 스킵도 지원한다.
- 장수 120명에 각각 초상 이미지를 연결했다. 목록·상세·편집·전투 정보에서 같은 사진을 사용한다. 기존 삼국영지 이미지 56명과 새로 생성한 64명으로 구성하며 이름·소속·능력치를 바꾸어도 초상은 유지한다. [이미지와 생성 프롬프트](ART_ASSETS.md).
- PK에서 검색·세력 필터, 5개 능력치, 배치 도시·소속과 신장수 등록을 지원한다. 상세·편집의 3D 미리보기와 외형 수정 기능은 제거했다. 임무 중에는 배치 이동 금지. 편집 미저장 상태에서 전환하면 버리기 여부를 확인한다.
- 편집과 신장수는 현재 국면의 저장 파일에 포함된다. 신규 게임에는 기본 명단을 사용한다. 이전 저장에는 누락된 PK 장수를 추가하며 기존 편집은 유지한다. StrictMode의 재마운트에서도 이어하기 데이터를 복원한다.
- 3D 모듈은 해당 게임에 진입할 때 로드한다. 지도는 변경/애니메이션이 있을 때만 그린다. 지도·전투의 모델과 기존 저장의 외형 정보는 호환성을 위해 유지한다.

## 범위

원작 자산을 사용하지 않은 자체 제작 로우폴리 3D 모델이다. 실제 폴리곤과 조명·그림자를 사용하지만 고해상도 실사 인물이나 원작 모델의 재현은 아니다. 현재 시나리오는 중원 12개 도시, 7세력, 120장수와 창·기·궁 3병과다. 중국 전역 지도, 수군·공성 병기, 일기토·설전, 외교와 PK 시설 흡수합병은 구현하지 않았다.

## 검증

`npm test`, `npm run build`. PK 편집·신장수 출진·구 저장 보강·달력·내정·전투와 함께 120명 초상 연결, 이름 변경 후 초상 유지, 상세·편집의 이미지 출력, 메인 시작 자원, 도시 탐색의 상태 불변을 자동 검사한다. 생성한 초상 시트는 직접 시각 검사했다. 이번 UI 변경에서는 연결 가능한 브라우저가 없어 실제 화면 크기별 조작 검증은 수행하지 못했다. 이전 버전의 브라우저 검증을 이번 변경의 검증으로 간주하지 않는다.
