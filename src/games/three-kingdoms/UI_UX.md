## 적용

- 검은 지휘실과 금색 명령 버튼으로 인터페이스를 전면 개편했다. 시작 화면은 허브의 전장 일러스트와 군주 초상을 사용하며, 지도 색과 UI 색은 별도 팔레트로 관리한다.
- 메인은 세력 선택, 실제 시작 자원·주요 장수 확인, 명시적인 시작 버튼으로 구성했다. 이어하기는 저장된 세력과 날짜를 표시한다.
- 지도 옆 도시 명령을 내정·군사·건설로 나누고 장수 검색·임무·선택 수를 표시한다. 예약 명령과 취소를 같은 패널에서 확인한다.
- 소유 도시 바로가기, 전도, 조언의 도시 탐색은 부대 이동·공격·건설을 실행하지 않는다. 턴 진행 중 충돌하는 입력은 잠근다.
- 모든 기본 장수 120명에 서로 다른 초상을 연결했다. 목록과 상세·편집의 사진은 같으며 외형 편집과 해당 화면의 3D 모델을 제거했다. 신장수는 기존 초상 중 하나를 안정적으로 배정한다.
- 데스크톱은 군주·도시 목록, 지도, 명령 패널의 세 영역으로 구성한다. 날짜·자원·시간 진행은 상단에 모은다. 모바일은 도시 바로가기를 가로로 배치하고 조언을 펼침 메뉴로 제공한다. 지도 아래 명령 패널을 접어 전장을 넓힐 수 있다. 메인은 한 열로 전환한다.
- 실제 3D 지도는 이어지는 지면·산 능선·부드러운 강둑·도시 사이 가도를 사용한다. 성곽에는 벽돌 줄눈·여장·문루·기와 처마·군기를 추가하고, 나무는 가지와 작은 수관을 조합한다. 농지·시장·병영·진지·궁노대도 서로 다른 모델이다. 출진 부대는 창병의 방패·장창, 궁병의 활, 기병의 말과 대열을 사용한다. 정적 모델은 색상별로 합쳐 그리며, 도시 위 부대는 성문 옆에 표시한다.
- 장수 편집의 다섯 능력치는 입력 즉시 1~100의 정수로 제한한다. 지수·부호·소수점 입력을 막고 범위를 안내하며, 저장 로직에서도 범위 밖 능력치를 거부한다.
- 지도 세력 선택의 키보드 입력, 모달의 초점 이동·복귀·Escape 닫기와 초상 대체 설명을 제공한다.

## 검증 범위

규칙 테스트와 UI 서버 렌더링 테스트로 초상 연결·자산 존재·이름 변경 후 초상 유지·외형 편집 제거·시작 자원·탐색의 상태 불변을 확인한다. 생성 이미지 네 장의 4×4 배치와 얼굴 구분은 직접 시각 검사했다.

2026년 10월 개편은 실제 브라우저에서 데스크톱과 모바일 시작·플레이 화면, 출진 편성·실제 출진, 도시 탐색과 명령 패널을 확인했다. 장수 편집창 안내 문구의 명암비와 닫기 후 초점 복귀를 수정하고, 저장하지 않은 편집의 보호 동작을 확인했다. 320px·390px 모바일에서 가로 넘침이 없고, 플레이 화면과 편집창의 WCAG 2 A/AA 자동 검사 위반은 0건이다. 검증 화면은 `docs/screenshots/pk-*`에 기록했다.
