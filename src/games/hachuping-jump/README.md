# 하츄핑 점프

탭으로 날아 장애물 사이를 통과하는 게임. 플래피 버드 계열이지만 **끝이 있다.**

## 무한이 아니라 여섯 세계

보통 이런 게임은 죽을 때까지 달린다. 그러면 잘하는 사람에게만 끝이 있고, 아이에게는 영원히
끝나지 않는 실패가 된다. 그래서 `stages.ts`에 세계 여섯 개를 두고 각 세계를 문 24개로 끊었다.
공중 정원 → 버섯숲 → 얼음성 → 장난감 마을 → 별궁전 → 무지개 하늘, 그리고 **완주**가 있다.

난이도는 세계 안에서도, 세계를 넘어서도 이어서 올라간다. 속도 185 → 245, 문 간격 235 → 190.
단계마다 뚝 끊기지 않고 `speedStart`/`speedEnd`로 그 세계 안에서 서서히 변한다.

세계 사이에는 체크포인트가 3초 들어간다. 숨 돌릴 자리이자 "여기까지 왔다"를 보여 주는 자리다.

## 날갯짓 연습이 실제 물리에서 나온다

`practice.ts`의 `PRACTICE_INTERVAL`은 손으로 정한 숫자가 아니다.

```ts
export const PRACTICE_INTERVAL = -2 * FLAP_IMPULSE / GRAVITY;
```

올라갔다 제자리로 내려오는 데 걸리는 시간을 중력과 날갯짓 세기에서 바로 계산한다. 그래서
물리 상수를 고쳐도 연습이 가르치는 박자가 따라 바뀐다. 손으로 적어 둔 0.58초였다면 중력을
만지는 순간 연습이 틀린 걸 가르치기 시작했을 것이다.

세 번 연속 맞히면 `complete`. 잘할 때까지가 아니라 "감을 잡았다" 싶은 선에서 끊는다.

## 연타로 하늘을 걸어 올라갈 수 없게

`FLAP_IMPULSE`는 속도에 **더하는** 게 아니라 속도를 그 값으로 **세팅한다**. 더하는 방식이면
빠르게 연타할수록 위로 솟구쳐서, 장애물을 무시하고 천장을 따라 달리는 공략이 생긴다. 상수
주석에 이 이유가 박혀 있다.

보이는 것(`PLAYER_RADIUS` 18)보다 판정(`PLAYER_HITBOX_RADIUS` 14)이 작다. 스쳤는데 죽었다는
느낌은 이 장르에서 가장 억울한 죽음이다.

## 아이템은 데미지보다 먼저 처리한다

`resolveRewards`는 줍는 것을 먼저, 부딪히는 것을 나중에 본다. 같은 프레임에 방패를 줍고
장애물에 닿으면 **방패가 막아 준다.** 순서를 뒤집으면 "방패를 주운 순간 죽는" 판이 나온다.

## 기록은 완주 모드만 센다

`meta.ts`의 `bestMode: "full"`. 나중 세계에서 시작한 판은 별도 모드로 들어가 최고 기록을
밀어내지 않는다. 다섯 번째 세계에서 시작해 받은 점수가 처음부터 날아온 점수와 같은 줄에 서면
기록이 의미를 잃는다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `game/constants.ts` | 물리와 균형 숫자 |
| `game/stages.ts` | 세계 여섯 개의 정의와 진행 상태 기계 |
| `game/engine.ts` | 한 프레임 진행 |
| `game/rewards.ts` | 아이템·별·충돌 판정 (순서가 중요) |
| `game/practice.ts` | 날갯짓 연습 |
| `game/obstacle*.ts` | 장애물 모양과 생성 |
| `hooks/useJumpEngine.ts` | React와 엔진 연결 |

## 아직 하지 않은 것

- 세계 여섯 개가 전부 "날아서 통과"다. 세계마다 다른 조작이 들어가면 완주가 더 긴 여정이 된다.
