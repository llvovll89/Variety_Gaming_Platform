# 밥상 대격돌

게임 허브에서 **밥상 대격돌**을 선택하세요. 개발 서버는 프로젝트 루트에서 `npm run dev`로 실행합니다.

Three.js로 그리는 3D 주방 격투게임입니다. 기본 선수는 관절 모델로, 팔꿈치와 무릎을 IK로 계산합니다(`pose.ts`). 무기는 손에 고정돼 있고, 기술마다 예비동작 → 스윙 → 접촉 → 팔로스루 궤적이 따로 있습니다. 접촉 순간 무기 끝 위치가 판정 사거리와 일치합니다. 맞으면 히트스톱, 몸 번쩍임, 감속 넉백이 이어집니다. 카메라는 두 선수의 중간을 따라가며 거리에 맞춰 확대·축소합니다.

내 사진을 넣으면 원본 비율을 유지한 판으로 선수 대신 표시합니다. 투명 PNG/WebP는 알파를 보존하며 최대 1024px로 줄여 로컬 저장소에 보관합니다.

허브 썸네일(`public/art/hub/kitchen-fighter*.jpg`)은 실제 경기 화면을 캡처한 것입니다.

- 주걱: 균형형. 파리채: 빠르지만 약한 타격. 골프채: 느리지만 강하고 긴 사거리.
- 60초 라운드, 2선승. 동률은 승점을 부여하지 않고 다음 라운드로 넘어갑니다.
- CPU 쉬움/보통 또는 같은 키보드의 2인 대전. 터치 버튼은 1P 조작입니다.
- 상·중·하단 타격, 서기/앉기 가드, 뒤로 걷기 자동 가드, 대시/백대시, 사이드스텝, 점프, 띄우기, 공중 연타 및 콤보 보정.
- 공격하거나 맞으면 게이지 증가. 100%에서 필살기 사용 시 소모합니다.
- Web Audio의 짧은 노이즈와 공명음을 합성해 나무 주걱의 찰싹 소리, 파리채의 높은 소리, 골프채의 금속성 소리를 만듭니다. 실제 녹음 샘플은 아닙니다.
- Esc, 창 포커스 이동, 탭 숨김 시 일시정지. 게임 종료 시 애니메이션, 이벤트, 오디오 컨텍스트 해제.

| 조작 | 1P | 2P |
|---|---|---|
| 이동 / 대시 | A / D, 두 번 빠르게 누르면 대시. CPU 대전에서는 ← / →도 가능 | ← / → |
| 사이드스텝 | Q / E 톡 치면 빠른 회피, 누르고 있으면 옆걸음 | Home / End |
| 점프 / 앉기 | W / S (CPU 대전에서는 ↑ / ↓도 가능) | ↑ / ↓ |
| 가드 | Shift 또는 Space, 뒤로 걸어도 가드 | 0 |
| 약공격 / 강공격 / 하단 | J / K / L | 1 / 2 / 3 |
| 띄우기 / 필살기 | U / I | 4 / 5 |

1P는 S → 상대 방향(A 또는 D) → J를 빠르게 입력해 띄우기를 사용할 수도 있습니다. 2P는 숫자열 또는 숫자 패드 사용 가능. 일부 키보드에서는 많은 키를 동시에 누르면 입력 제한이 있을 수 있습니다.

전투 로직 검증: `node --test tests/kitchen-fighter.test.mjs`.
