# 룬 레인저

기존 오브 피하기를 대체한 Canvas 2D 자동 사격 생존 RPG입니다. 기존 허브 ID는 유지합니다. 다른 게임의 캐릭터와 리소스는 변경하지 않습니다.

- 이동: WASD / 방향키 / 화면을 누른 채 드래그
- 난이도: 쉬움 / 보통 / 어려움 / 악몽. 메뉴 기본 선택은 어려움이며 재시작·지역 이동 시 유지됩니다. 높은 난이도는 적 체력·이동·출현 빈도·피해·탄속·공격 빈도·보스 탄환 수가 증가합니다.
- 전투 모델과 충돌 반경은 최초 버전의 65%입니다. 빠른 탄환은 이동 구간 전체로 충돌을 검사합니다.
- 무기 선택: 룬 장검(125 범위 부채꼴 공격), 룬 소총(560 범위), 광자 레이저(620 범위 관통), 산탄총(300 범위 5발 확산). 모두 자동 조준·공격하며 강화가 적용됩니다.
- 캐릭터: 레인저(기동), 기사(체력·방어), 마도사(공격·경험치), 기계병(체력·연사)은 서로 다른 기본 능력치를 가집니다. 의상 4색은 능력치에 영향을 주지 않습니다. 무기·모델·색상은 로컬에 저장됩니다.
- 숙련 조합: 레인저+소총 공격 속도 20% 증가 / 기사+장검 피해 25% 증가 / 마도사+레이저 피해 25% 증가 / 기계병+산탄총 2발 추가. 모든 캐릭터가 모든 무기를 사용 가능합니다.
- 준비 화면: 진입 즉시 캐릭터 선택, 무기는 같은 위치의 탭으로 선택. 능력치·숙련 보너스·전직 로드맵을 함께 표시합니다.
- 성장: 최대 LV 60. 다음 레벨 경험치는 `12 + (현재 레벨 - 1) × 6`, 지역별 경험치 보상은 `기본 보상 × (1 + 지역 인덱스 × 0.35)`입니다. 최대 레벨에서도 마지막 일반 강화를 1회 제공하며 이후 경험치는 누적하지 않습니다.
- 전직: LV 10 / 25 / 40에 1·2·3차 전직. 1차에서 캐릭터별 두 계열 중 하나를 선택하고 2·3차는 해당 계열의 강습(스킬 위력) / 수호(체력·방어)를 선택합니다. 전직 시 전투 정지, 일반 레벨업 강화와 초과 경험치 유지. 원정 재시작 시 전직 초기화.
- 전직 외형: 8개 계열 전용 투구·장비, 2차 망토·추가 갑옷, 3차 날개·왕관·기계 장비를 적용합니다. 강습/수호는 장비 재질과 최종 장식도 다릅니다. 선택 창의 외형 미리보기와 전장 모델은 같은 렌더러를 사용합니다.
- 직업 스킬은 조건 충족 시 자동 발동: 명사수(관통 저격), 덫 사냥꾼(속박), 광전사(회전 참격·회복), 성기사(성역·보호막), 화염술사(폭발), 빙결술사(광역 둔화), 포격병(최대 3기 타격), 정비사(회복·적 탄환 제거). 전직할수록 스킬 단계와 고유 특성도 강화됩니다.
- 적: 병사 / 마법사 / 중장병 / 슬라임 / 박쥐 / 골렘 / 중간보스 / 보스. 스테이지마다 출현 구성이 다르며 박쥐는 빠르고, 골렘은 느리지만 체력과 접촉 피해가 높습니다.
- 레벨업: 경험치 결정 수집 후 무작위 능력 3개 중 선택 (클릭 또는 1·2·3)
- 일시정지: P / Escape / 우측 상단 버튼. 창 전환 시 자동 정지
- 중간보스: 각 스테이지 전투 시간 25초에 등장. 처치 시 체력 30 회복
- 보스: 60초 경과 및 중간보스 처치 후 등장. 방사형 공격 전 0.8초간 예고
- 스테이지: 이끼빛 전초지 → 잿불의 성채 → 서리의 협곡 → 독안개의 늪 → 수정 심연 → 월식의 왕좌. 다음 지역에서 체력 전부 회복, 성장과 선택 장비 유지
- 최종 보스 격파 시 승리. 새 원정은 레벨 1부터 시작
- 최고 처치 기록은 난이도별로 브라우저 로컬 저장소에 보관 (기존 통합 기록은 덮어쓰지 않음)

`world.ts`는 DOM에 의존하지 않는 시뮬레이션, `classes.ts`는 캐릭터·전직 데이터, `render.ts`는 캐릭터·전장·스킬 연출, `Preparation.tsx`는 준비 화면, `SurvivorApp.tsx`는 입력·게임 루프·HUD·전직 창을 담당합니다. 캐릭터는 입체감을 표현한 2D 벡터 모델이며 전직 시 계열 색상 오라와 단계 표식이 표시됩니다.

검증: Node.js 22.18+ 또는 24에서 `npm test`, 배포 빌드는 `npm run build`.

개발 모드에서만 `window.__ranger`를 통해 월드 상태와 시뮬레이션 함수에 접근할 수 있습니다. 배포 빌드에서는 제공하지 않습니다.
