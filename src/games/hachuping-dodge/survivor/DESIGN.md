# 룬 레인저 디자인

## 기준

허브 썸네일 `public/art/hub/hachuping-dodge.jpg`의 녹색 후드, 가죽 장구,
무광 금속, 이끼 낀 유적을 게임에 연결한다. 녹색 과잉에 대한 피드백에 따라
공통 UI는 차콜과 석재로, 녹색은 레인저와 일부 이끼로 제한한다. 기존 게임 ID, 성장과 전직,
무기 성능, 충돌 반경, 저장 형식은 유지한다.

기존 화면은 민트색 도형과 패널이 반복되고, 캐릭터 선택 화면에서
작은 미리보기만 제공했다. 색상과 장비 재질을 정리하고 큰 영웅 미리보기를
중심으로 준비 화면을 재구성했다. 마케팅 페이지의 장식과 스크롤 효과는
전투와 장비 선택에 필요하지 않아 사용하지 않는다.

## 토큰과 구성

- 공통 바탕 `#24262d`, 패널 `#30333d`, 철 `#919aaa`, 버튼 `#d9ba87`, 글자 `#eeebf1`.
- 영웅 고유색: 레인저 `#9dca94`, 기사 `#e2bc78`, 마도사 `#bba5ee`, 기계병 `#e89b6c`, 암살자 `#de9eb9`, 창기사 `#8ecbe9`.
- 글꼴은 기존 자체 호스팅 Pretendard. 제목 25-38px, 영웅 이름 20-24px, 선택 정보 11-14px.
- 장비와 버튼 모서리 3px, 모달 6px. 영웅 선택은 고유색 테두리와 안쪽 선으로 표시한다.
- 변화 7, UI 모션 3, 밀도 5. UI 움직임은 누르기 피드백에 한정한다.
- 석판과 기둥은 회색 재질로 통일하고 이끼의 빈도를 줄인다. 지역색은 전장의 룬에 사용한다.

```text
데스크톱: [영웅 / 무기 선택] [큰 영웅 미리보기] [능력치 / 전직 계열]
          [난이도와 기록                              원정 시작]
모바일:   [영웅 미리보기] [선택] [능력치와 전직] [고정된 원정 시작]
```

썸네일은 기존 실제 이미지 자산을 사용한다. 움직이는 캐릭터와 장비는
기존 Canvas 2D 렌더링을 확장한다. `heroModels.ts`의 여섯 몸체와
`models.ts`의 무기를 미리보기와 전투에 공유한다. `heroEffects.ts`는
영웅별 참격, 탄도, 발사와 명중, 번개와 전직 스킬을 그린다.
`terrain.ts`의 정적 지형은 지역별 캔버스에 캐시한다.

월영 암살자는 그림자 검객 / 영혼 사냥꾼, 폭풍 창기사는 뇌전술사 / 용창 기사로
전직한다. 두 영웅 모두 10 / 25 / 40레벨 성장과 강습 / 수호 선택을 지원한다.
장식색을 바꿔도 기본 의상과 고유 이펙트는 유지된다. 선택 시 숙련 무기를
장착하며 이후 무기 탭에서 다른 계열로 바꿀 수 있다.

## 검증

- 프로덕션 빌드, 기존 전투 및 신규 스킬 검증을 포함한 테스트 31개.
- 브라우저에서 390×844, 1264×569, 1440×900 화면과 전직 선택을 확인.
- 390×844 준비 화면에서 가로 넘침 없음, 시작 버튼 노출, 버튼 잘림 없음.
- 영웅 / 무기 탭에 방향키, Home, End 이동과 선택 탭의 포커스 순서 적용.
- 전투 화면 axe WCAG A/AA 자동 위반 0개. Canvas 위의 대비 항목은
  자동 판정이 불가능하므로 어두운 HUD 배경과 밝은 글자의 대비를 직접 확인한다.
- Lighthouse는 허브 진입 페이지를 검사한다. 게임의 Canvas 프레임 성능을
  측정하는 결과로 해석하지 않는다.
