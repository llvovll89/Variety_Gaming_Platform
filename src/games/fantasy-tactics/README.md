# 별빛 원정대

파랜드 택틱스 1의 쿼터뷰 전술 RPG 구성을 참고한 오리지널 웹 게임 프로토타입.
허브에서 **별빛 원정대**를 선택하면 실행된다.

## 현재 플레이 범위

- 동료 4명: 아린(검사), 테오(창병), 리아(마법사), 노아(치유사).
- 3개 전투: 여울숲의 다리, 바람 언덕의 고지, 별의 등대의 보스.
- 맵 위 대화 → 전투 → 보상·성장 → 캠프 → 다음 장 → 엔딩.
- 첫 번째·두 번째 승리 뒤 모닥불 캠프. 동료별 대화, 다음 목적지 지도·전투 조언, HP·MP 회복과 회복약 보충.
- 캠프의 선택한 대화·읽던 줄·읽은 동료·지도 확인 상태를 자동 저장. 동료 대화는 선택 사항이며 바로 출발할 수 있다.
- 이동, 공격, 동료별 스킬 2개, 회복약, 대기.
- 개인 경험치·레벨 상승, 다음 장에서 HP·MP와 회복약 복구.
- 자동 저장과 이어하기, 일시 정지, 패배 후 같은 전투 재도전.
- 마우스·터치·키보드 조작. 모바일에서는 지도 아래의 동료·행동 선택창 사용.
- 동료·적 7종의 네 방향 표현, 경로를 따르는 보행, 무기 공격·마법 시전·피격·쓰러짐 연출.

## 첫 버전의 규칙

아군과 적군이 교대로 행동한다. 아군 차례에 각 동료는 이동 1회 후 행동 1회가 가능하다.
공격·스킬·회복약을 사용하거나 대기하면 그 동료의 행동이 끝난다. 이동하지 않고 행동할 수도 있다.
동료 모두 행동하면 자동으로 적 차례가 시작된다. 차례 마치기 버튼은 남은 동료의 행동을 건너뛴다.

물과 살아 있는 유닛은 통과할 수 없다. 이동 시 한 칸 사이의 높이 차이는 1단계까지 허용한다.
높이 차이 한 단계마다 공격 피해가 12% 변하며, 보정은 최대 두 단계까지 적용한다.
검사·창병이 같은 높이에서 직선으로 세 칸 이상 이동한 뒤 바로 앞의 적을 일반 공격하면 피해가 1.5배가 된다.
돌진과 이동 취소 기록은 유닛마다 유지되며 저장 후 복구된다. 원래 위치에 다른 유닛이 있으면 이동 취소할 수 없다.

불꽃별은 중심과 상하좌우의 적만 공격한다. 아군 피해와 반격은 첫 버전에 없다.
보호 효과는 피해를 35% 줄인다. 시전 후 다음 두 적 차례 동안 유효하다.
회복·보호는 실제로 효과가 생기는 경우에만 경험치를 준다. MP는 전투 중 자동 회복되지 않는다.
전투 불능 유닛은 전장에서 사라지고 다음 장 또는 재도전 시 회복한다. 마지막 전투는 보스 격파가 승리 조건이다.

위 수치와 규칙은 이 게임의 설계안이며 원작 규칙의 정확한 재현이 아니다.

## 장비와 보물상자

무기 12종·방어구 6종·장신구 6종, 총 24종의 고유 장비를 수집한다. 각 전장에는 보물상자 3개가 있으며 총 9개다. 상자와 같은 칸 또는 인접한 칸에서 열 수 있고 행동 1회를 소비한다. 재도전해도 열린 상자의 전리품은 다시 지급하지 않는다.

캠프의 장비 정비에서 동료별 무기·방어구·장신구를 장착한다. 장착 전후 능력치를 비교하며 직업 제한과 다른 동료의 사용 여부를 표시한다. 공격·방어·이동·스킬 MP·회복·돌진 효과를 전투에 반영하고, 획득·장착·개봉 기록은 저장한다. 이전 저장 파일도 기본 장비를 지급해 이어갈 수 있다.

## 구현 파일

- `game.ts`: DOM과 분리된 전투 상태, 사각 격자 탐색, 스킬·피해·성장·목표·AI·저장 검증.
- `render.ts`: 쿼터뷰 Canvas 지형, 캐릭터 자세·타격·마법 표현, 칸과 유닛 선택.
- `art.ts`: 생성된 초상·스프라이트·42개 자세 로딩 및 프레임 추출.
- `animation.ts`: 방향, 실제 경로의 이동 시간과 이동 후 공격 시간 계산.
- `camp.ts`, `CampScreen.tsx`, `camp.css`: 두 야영지의 대화, 모닥불 장면, 초상 선택, 지도와 출발.
- `equipment.ts`, `GearPanel.tsx`, `gear.css`: 장비 24종, 상자 배치와 전리품, 장착과 능력치 비교.
- `FantasyTacticsApp.tsx`: 명령창, 초상, 동료 선택, 대화, 결과, 일시 정지와 저장.
- `tactics.css`: 남색 전투창과 금빛 강조, 반응형 배치, 모바일 조작창.

React는 이벤트와 턴 변화 때 UI를 갱신한다. Canvas의 rAF는 짧은 이동·공격 연출 중에만 돈다.
AI는 같은 이동 탐색과 피해 함수를 사용한다. 적 차례는 한 유닛씩 타이머로 진행되며 일시 정지하면 중단된다.
저장은 `gh-arcade:fantasy-tactics:v1` 키를 사용하고 zod로 버전·유닛 정체성·좌표·능력치·이동 경로를 검증한다.
저장 공간이 막힌 브라우저에서도 게임은 계속 진행할 수 있고 저장 불가 메시지가 표시된다.

## 검증

```sh
node --test tests/fantasy-tactics.test.mjs
npm run build
```

전투 테스트 20개는 이동 제한·돌진·동료 전환·회복·범위 공격·보호·AI·승패·저장 검증과
실제 명령을 사용하는 세 장의 자동 플레이를 포함한다.
애니메이션 경로의 칸별 보간과 적의 이동 후 공격, 범위 타격 대상도 확인한다.
두 캠프의 회복·대화·정확한 저장 복원·이전 저장 호환·다음 장 진행도 검증한다.
장비 효과, 장착 제한, 상자 접근성·보상·재도전 중복 방지와 저장 검증도 포함한다.
브라우저에서 허브 진입, 대화, 키보드 이동·취소, 적 차례, 모바일 동료 선택·회복,
새로고침 후 이어하기, 승리 후 다음 장, 결과·엔딩과 재도전 화면을 확인한다.

## 다음 확장

현재 캐릭터는 새로 생성한 2D 스프라이트와 초상이며 네 방향의 기본 보행·공격을 지원한다.
앞·뒤 원본 자세를 좌우 반전하며 보행은 대기와 보행 자세 두 장을 교대로 표시한다.
사운드, 상점, 다양한 표정과 맵 편집기는 아직 구현하지 않았다.
추가 콘텐츠 전에 직접 플레이 피드백으로 화면 크기, 전투 템포와 직업 밸런스를 조정한다.
