# 하츄핑 풍선

올라오는 풍선을 손가락으로 톡톡 터뜨리는 60초짜리 장난감. 지는 판이 없다.

## 실패가 없는데 왜 점점 빨라지나

놓친 풍선은 화면 위로 사라질 뿐이고, 목숨도 체력도 없다. `constants.ts`의 주석이 램프의 목적을
못 박아 둔다 — **"장난감이 긴 시간 동안 생기 있게 느껴지게 하려는 것이지 플레이어를 위협하려는
것이 아니다."** 그래서 올라오는 속도도(75 → 170), 생성 간격도(0.85초 → 0.35초) 상한이 낮다.

대신 끝은 있다. 예전에는 무한이라 그만둘 자리가 없었다. 지금은 `GAME_DURATION_SECONDS = 60`
한 판으로 끊어서, 아이가 "한 판 더"를 스스로 고르게 한다.

## 규칙적인 리듬을 일부러 깬다

이 게임에서 가장 공들인 부분은 난이도가 아니라 **불규칙성**이다. 세 군데에 흔들림을 넣었다.

- 풍선마다 올라오는 속도에 0.65~1.5배의 편차. 연달아 나온 풍선이 나란히 줄지어 올라가지 않는다.
- 파도 간격에 0.5~1.7배의 편차. 메트로놈처럼 똑딱이지 않는다.
- `balloonsPerWave`는 개수가 아니라 **상한**이다. 매번 1개에서 그 상한 사이로 굴린다.

셋 다 빼도 게임은 돌아간다. 다만 2분쯤 지나면 눈이 패턴을 외워 버려서, 보지 않고도 손이 먼저 간다.

## 작은 손을 위한 판정

풍선 반지름이 30~42px인데 판정은 거기서 `BALLOON_HIT_PADDING = 8`만큼 더 넉넉하다. 보이는
것보다 크게 잡히는 쪽이, 아이가 "분명히 눌렀는데"라고 말하는 일을 줄인다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `game/engine.ts` | 풍선 생성·상승·터뜨리기, 램프, HUD 스냅샷 발행 |
| `game/constants.ts` | 숫자 전부. 균형을 만지려면 여기만 보면 된다 |
| `game/render.ts` | 캔버스 그리기 |
| `HachupingBalloonApp.tsx` | 화면, 입력, 기록 보고 |

HUD는 매 프레임이 아니라 `UI_PUBLISH_INTERVAL`(0.12초)마다 키트의 스냅샷 스토어로 흘려보낸다.
React가 초당 60번 다시 그릴 이유가 없다.

## 아직 하지 않은 것

- 풍선 종류가 색만 다르다. 두 번 눌러야 터지는 풍선 같은 변주가 없다.
- 마스코트는 장식이고 상호작용이 없다.
